# Flip-scanner Mobile Web

Dette er en simpel iPhone-venlig webversion.

## Sådan bruger du den på iPhone
1. Pak zip-filen ud på en computer.
2. Åbn `index.html` i en browser for at teste den.
3. Upload `index.html` til fx Netlify, GitHub Pages eller dit eget webhotel.
4. Åbn linket på din iPhone i Safari.
5. Du kan gemme siden på hjemmeskærmen via:
   Del -> Føj til hjemmeskærm

## Fordel
Den kræver ikke Python for brugeren, når den først ligger online.
