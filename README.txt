Sarah's Adventure – host-klar webversion

Sådan tester du den rigtigt på iPhone:
1. Pak zip-filen ud
2. Upload mappen til Netlify eller GitHub Pages
3. Åbn det hostede link i Safari

Hurtigste vej:
- Netlify Drop
- Træk hele mappen ind
- Åbn det genererede link

Indhold:
- index.html (selvkørende, alle sprites embedded)
- ingen ekstra assets kræves

Bemærk:
Lokale HTML previews på iPhone kan blokere JavaScript/canvas.
Derfor er hosting den rigtige vej.
